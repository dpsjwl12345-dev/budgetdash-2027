# Civic Ledger 개선본 디자인 기준

## 참조 화면
사용자가 제공한 배포 화면 `https://budgetdash-bnwfk4np.manus.space/`를 시각적 기준으로 삼는다. 현재의 **어두운 네이비 행정 업무용 대시보드**, 좌측 고정 사이드바, 상단 업무 컨텍스트, 카드형 핵심 지표, 상태 기반 예산 테이블의 구조를 유지한다.

## 이번 변경의 범위
이번 작업은 사용자가 요청한 **전체 폰트 크기 확대**만 수행한다. 모바일 레이아웃, 정보 구조, 데이터 내용, 메뉴 구성, 색상 체계, 업무 기능은 임의로 변경하지 않는다. 데스크톱 화면에서 더 편하게 읽히도록 본문·라벨·메타 정보·표의 행간을 함께 조정한다.

## 보존할 디자인 원칙
- **정보 우선순위 보존:** 화면의 예산 검토 흐름과 상태 색상 체계를 유지하고 글자 크기만 키워 읽기 부담을 줄인다.
- **업무용 밀도 유지:** 무작정 확대해 한 화면에 보이는 정보량을 잃지 않도록 제목과 본문, 메타 정보의 비율을 조절한다.
- **대비와 계층 강화:** 작은 회색 보조 문구도 충분히 읽히도록 최소 크기와 줄 높이를 상향한다.
- **데스크톱 기준:** 넓은 테이블과 다중 열을 전제로 하며 모바일 전용 재배치는 하지 않는다.

## 타이포그래피 조정 기준
- 전체 기본 글자 크기를 현재보다 한 단계 크게 조정한다.
- 페이지 제목과 섹션 제목은 시각적 위계를 유지하면서 약 10~15% 확대한다.
- 카드 수치는 가장 눈에 띄는 정보이므로 본문보다 큰 단계로 유지한다.
- 표 머리글·본문·상태 배지는 모두 읽기 쉬운 최소 크기로 통일한다.
- 폰트 확대에 맞춰 버튼 높이, 카드 내부 여백, 표 행 높이와 줄 높이를 함께 조정한다.

## 구현 메모
CSS와 페이지 컴포넌트의 상단에 이 기준을 상기하는 주석을 둔다. 새로운 이미지나 장식 요소는 추가하지 않는다. 질문이 생기면 “이 선택이 참조 대시보드의 업무 가독성을 높이는가, 아니면 범위를 넓히는가?”를 기준으로 판단한다.
